# Portfolio OS — Phase 1

Single-owner, approval-gated AI portfolio manager using Python, OpenAI Responses API, Codex work briefs, and a private Supabase/PostgreSQL schema.

**Deployment in progress. Paid execution is paused by default.**

This public repository contains engine code and synthetic examples only. Real project briefs, customer observations, research, generated artifacts, credentials, and personal data must not be committed here.

Human-active projects are limited to three. AI may propose bounded research or a Codex work brief; it cannot publish, contact customers, execute generated code, or approve its own proposals.

The initial implementation is being added on a review branch. See the pull request and `BUILD_STATUS.md` for verified capabilities and remaining deployment steps. Connecting ChatGPT to GitHub/Supabase does not give an external worker an OpenAI API key or a database login.
